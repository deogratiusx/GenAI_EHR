Insights

What we learned about tool use

The interface matters as much as the model

With the same tools a local 4B model scored 0.89, GigaChat Max 0.88 (Δ +0.01, CI ±0.06).

Domain fine-tuning did not transfer

Med-Qwen trailed its own base by 0.11 (CI −0.18…−0.04; borderline after Holm): through tools, instruction following counts more than medical knowledge.

Weak models need a harness, not more tools

Lite is 0.25 below Max with the same tools; the harness adds +0.10 for Lite, +0.04 for Max. Match tools and checks to the model.

Enumerate, don’t search, when recall matters

Summaries failed by omission; a deterministic dossier plus a coverage check fixed it.

Each insight has a measured basis: the first two from the final run, the last two from the iteration analysis and the summary experiment.
