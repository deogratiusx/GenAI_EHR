What we learned about tool use

The interface matters as much as the model

A 4B model with good tools reached 0.93 on inpatient PDFs in exploration. [[confirm with final run]]

Domain fine-tuning did not transfer

Med-Qwen trailed its own base by 0.05–0.10: through tools, instruction following counts more than medical knowledge. [[confirm]]

Weak models need a harness, not more tools

For Lite, extra tools lowered accuracy while robust answer handling raised it. Match the tool set to the model.

Enumerate, don’t search, when recall matters

Summaries failed by omission; a deterministic dossier plus a coverage check fixed it.
