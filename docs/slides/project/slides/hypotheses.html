Research question

Can tool design close the gap in model size?

Goal: a research probe of how far small local models and GigaChat can be pushed by the interface around them — not a finished clinical product.

#HypothesisComparison
H1Tools beat a code interpreter and match the whole record in context at a fraction of the cost; the harness helpstools vs code, record, map-reduce, tools without harness
H2A dossier and a report schema raise the completeness of a whole-record summary; completeness checks add to itreport vs tools, report without checks
H3Medical fine-tuning of the same base brings no gain when working through toolsMed-Qwen-4B vs Qwen3.5-4B
H4A small local model with tools is on par with a large cloud modelQwen3.5-4B vs GigaChat Max

Hypotheses and analysis fixed before the final run: paired permutation tests, Holm correction.

All comparisons are paired: the same questions for every system. Pre-registration protects the conclusions from being fitted to the numbers.
