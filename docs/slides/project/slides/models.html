One backend interface for all: chat(messages, tools, force_final) → text or {name, arguments}. Temperature 0. Same prompts, tools and harness for every model.

Excluded: foreign frontier APIs (data residency), GigaChat Pro (keep two contrasting tiers), a stronger control model (not available inside the constraints).

The pairs are deliberate: Lite vs Max isolates model size within one provider; Qwen vs Med-Qwen isolates medical fine-tuning on the same base; Qwen vs Max compares a small local model with a large cloud one. Forcing a final answer on GigaChat needed a workaround: the API accepts a forced call only when final_answer is the sole function in the list.
