Three ways to give an LLM the record

What general assistants do, and what we propose

Whole record in context

Simple, but 33–78k tokens per question, and a PDF history does not fit at all. Models lose the middle of long inputs and get distracted by irrelevant text.

Liu et al. 2023; Shi et al. 2023

Code interpreter

The model writes pandas code over the record table. Flexible, but a small model must itself know the schema, synonyms and reference ranges.

EHRAgent, Shi et al. 2024

Typed tools

Narrow functions with a JSON schema: lab value with its reference, search over conclusions, drugs by phase. Knowledge and arithmetic live in code; choosing and phrasing stay with the LLM.

ReAct, Toolformer, Gorilla / BFCL, SWE-agent ACI

The idea comes from the agent-computer interface of SWE-agent: an agent is only as good as the interface it is given. We design an interface to the medical record.
