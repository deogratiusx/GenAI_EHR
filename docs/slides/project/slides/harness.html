The harness

Deterministic checks around a probabilistic model

During the episode

  • Arguments validated against the schema; errors are repairable messages
  • Call budget, cache for repeated calls, explicit “empty” results
  • Routing by intent: weak models see only relevant tools
  • Text answer → forced final_answer: reasoning and format decoupled

Before an answer is accepted

  • Cited row ids must exist
  • Numbers must occur in the record or tool outputs
  • “Not found” triggers one broad search first
  • Reports: every critical item covered, verdicts agree with the data

Each check fires at most once per episode. Format constraints hurt reasoning (Tam et al. 2024), so the model answers freely first and is formatted second.

The harness is model-agnostic and deterministic. Its effect is measured as an ablation: tools with and without the harness.
