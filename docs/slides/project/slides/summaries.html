Whole-record summary and dynamics

Recall is the code’s job, the verdict is the model’s

1 · Dossier

Code enumerates every abnormal or changing lab with its trend, studies, diagnoses, drugs by phase, conflicts; ranks them critical / significant

2 · Report schema

The model writes one field per section: fact — value — verdict — trend — [id]; rendered into one document

3 · Checks

Every must-mention item covered or explicitly dismissed; no “normal” for a flagged value; trend direction matches the series

Critical recall (share of must-mention items covered) rises for every model, 9 inpatient and check-up records each.

On the 6 hand-written checklists the effect is mixed: Qwen 0.71 → 0.87, Max 0.72 → 0.72, Med-Qwen 0.60 → 0.40. The system was tuned on these summaries: an in-sample estimate.

Dynamics use the reference change value from biological variation: a change below RCV is measurement noise. Trends exist only in inpatient records, where labs repeat 3–5 times; each check-up is a single day.
